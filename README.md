## 📋 Sobre o Projeto

O **Task Manager Pro** simula uma ferramenta utilizada por equipes administrativas, atendimento ao cliente e suporte técnico para organizar atividades, acompanhar prazos e monitorar produtividade.

O sistema permite criar tarefas, definir responsáveis, controlar prioridades, pesquisar registros e acompanhar indicadores em tempo real através de um dashboard moderno.

Todos os dados são armazenados localmente no navegador utilizando LocalStorage, sem necessidade de backend.

---

## ✨ Funcionalidades

| Recurso | Descrição |
|----------|----------|
| 📌 Cadastro de tarefas | Registre atividades com responsável e prazo |
| 🚨 Prioridades | Classifique tarefas como Baixa, Média ou Alta |
| 🔍 Pesquisa em tempo real | Localize tarefas rapidamente |
| 📊 Dashboard | Indicadores automáticos de produtividade |
| ✅ Controle de conclusão | Marque tarefas como concluídas |
| 🌙 Dark Mode | Alternância entre tema claro e escuro |
| 💾 Persistência local | Dados armazenados via LocalStorage |
| 📱 Responsividade | Compatível com desktop e dispositivos móveis |
